## GitHub setup
Create an empty GitHub repository named `sanjeev-power-controls`, then run these commands from this folder:

```bash
git init
git add .
git commit -m "Initial commit: Sanjeev Power Controls website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/sanjeev-power-controls.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username and use the actual repository URL.
