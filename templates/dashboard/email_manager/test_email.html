Troubleshooting

  1. Save the SMTP settings before sending a test.
  2. Run Test SMTP connection first — it checks authentication without sending mail.
  3. For Gmail, use an App Password with 2-Step Verification enabled.
  4. For Microsoft 365, ask your administrator to enable SMTP AUTH for the mailbox.
  5. Port 587 normally uses STARTTLS; port 465 normally uses SSL/TLS. Never enable both.
  6. Check the sanitised error in Email Logs for the next step.
